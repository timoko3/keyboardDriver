# The Best debug tool in the world 
- It is a programm for debugging which shows all regs on pressing button '`' in English keyboard layout in beutiful eye-catching frame which is drawn with animation.

```bash
git clone https://github.com/timoko3/keyboardDriver.git
showreg.com
```
- and then just press '`' and enjoy regs of your processor:)
